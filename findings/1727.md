- **Signature:** cua-driver-x11-runtime-libs-1727
- **Evidence:** Measured on freshly fetched `origin/master` = `f37c78f87f9b390be85ad57be3b8af4d707e9526` (arm64 host, real staged binary `/home/asimov/.hermes/tools/cua-driver-0.52.0-linux-arm64/cua-driver`). - **Why:** `cua-driver` is the channel's default tool; the external Hermes PM installer's staged-entry check runs `cua-driver --version`, a dynamic-load smoke test that needs no display. The image's single apt layer omitted the three libraries, so the check failed and the shipped image carried a default tool that cannot run. Making the check headless-tolerant, skipping it, or forking the external installer were all rejected: no display is involved, a skip would drop the channel's default tool, and a second implementation of a channel decision is rule 6d churn.
