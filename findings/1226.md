# Findings — issue #1226 (live free-tier verification stamp)

## The local tier answered the model list but never a chat completion

- **Signature:** live-free-tier-verification-1226-chat-probe
- **Evidence:** `agents/model_chain.json` → `measured.local.chat_probe` records that `POST /v1/chat/completions (max_tokens 10)` timed out at both 45 s and 120 s on 2026-11-21 against `http://127.0.0.1:8080/v1`, while `GET /v1/models` on the same box answered one loaded model (`qwen3.8-flash-next-iq3_xxs`, 131072 context). The later `last_probe`/`probe_history` entries record `Connection refused` on 2026-11-23T00:47:05Z. The `measured.verified` stamp added by this change is an additive record of the 2026-11-21T20:14:30Z Nous catalogue read (HTTP 200, 415 models, five `:free` ids) and does not alter that evidence.
- **Why:** a model list answering is not proof the local inference route can serve a request. The chain's credential-less `local_fallback` tier is correct to stay in place (the fallback activates when the box serves), but without the timed-out chat probe recorded beside the successful model read a reader could mistake a live catalog for a working local endpoint.
- **Done when:** the timed-out chat probe stays traceable in the chain's `measured.local` record and this finding remains distinct from the free-tier verification stamp. The endpoint hang is already tracked as issue #1194, so no duplicate issue is owed from this record; this change adds no label and files no new issue.
