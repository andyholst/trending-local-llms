# Proposal: engine-guide-sync

Issue: #1220
PR: #1222

## Why

The README's inference-server guide and engine matrix are generated by the same render as
the trending lists, but nothing checked that a refresh re-rendered them. A PR could update
the data and leave the reader-facing server lists stale with every gate green. Measured:
50 guide rows / 50 registry engines / 49 measured engines / 49 matrix columns agree today —
which is exactly why the hole is invisible.

## What Changes

- scripts/engine_guide_check.py: read-only check of the guide table, the engine matrix
  columns, the store registry and the measured engines; names each drift finding and prints
  the re-render fix. Never writes or mutates the store (rule 3b).
- Makefile: `engine-guide-check` target and invocation from `_validate-search` (CI validate).
- tests/test_engine_guide_check.py: 14 checks incl. planted stale guide/matrix, shipped
  agreement and CI wiring.

## Impact

Specs: readme-render. Code: scripts/engine_guide_check.py, Makefile, test file.
No data or README content changes.
